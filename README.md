# Ads API

REST API для сайта объявлений.

## Технологии
- Python 3.11
- aiohttp
- SQLAlchemy
- SQLite
- Pydantic

## Как запустить (aiohttp)
1. Установить зависимости: `pip install -r requirements.txt`
2. Запустить сервер: `python app.py`

## Как проверить
Запустить `tests.py` (предварительно запустив сервер).
